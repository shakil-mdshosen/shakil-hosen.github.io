Teleprompter Controls

  • Play/Pause: Start or stop auto-scrolling
  • Reset: Return to the beginning of the script
  • Mirror: Flip text horizontally (useful for teleprompter mirrors)
  • Center Line: Show/hide reading guide line
  • Fullscreen: Enter/exit fullscreen mode
  • Speed: Adjust scrolling speed (1-10)
  • Font Size: Adjust text size (16-72px)
  • Scroll Wheel: Manual scrolling control
  • Spacebar: Quick play/pause

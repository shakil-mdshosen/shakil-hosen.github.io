📡 IP Range Expander

Enter one or more IP ranges in CIDR notation and get every individual IP address listed one per line.

How it works: Enter CIDR ranges (e.g. 178.176.72.0/24) one per line. Each range will be expanded into all its individual IP addresses. For safety, ranges larger than /8 (over 16 million IPs) are rejected. You can also check the expanded IPs against the Wikimedia global block list.
